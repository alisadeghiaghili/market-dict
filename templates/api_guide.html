📈 مستندات REST API دیکشنری مالی MarketDict

دیکشنری مالی MarketDict دارای بیش از ۶,۱۰۸ اصطلاح مالی غنی‌شده، ۳۲ دسته‌بندی تخصصی، ۴۴ فرمول محاسباتی ریاضی و موتور جستجوی هوشمند فازی به دو زبان انگلیسی و فارسی است. این API برای ادغام آسان با اپلیکیشن‌های وب، موبایل، بات‌های معاملاتی و هوش مصنوعی طراحی شده است.

BASE URL http://localhost:5000/api/v1
AUTH Open Access (None)
CORS Access-Control: *

۱. وضعیت سیستم و آمار (System Status)

GET /api/v1/health
وضعیت سلامت و پایداری سرور

اطلاعات سلامت سرویس، مدت زمان آپ‌تایم، وضعیت دیتابیس SQLite و تعداد کل اصطلاحات را برمی‌گرداند.

{"status": "success", "data": {"service": "MarketDict API", "status": "healthy", "uptime_seconds": 182.4, "total_terms": 6108, "database": "sqlite_wal_active"}}
GET /api/v1/stats
آمار محتوایی

آمار کل اصطلاحات، تعداد دسته‌بندی‌ها، تعداد حروف الفبا و تعداد اصطلاحات دارای فرمول محاسباتی.

۲. جستجو و اصطلاحات (Terms Search & Lookup)

GET /api/v1/terms
جستجو و فیلتر با صفحه‌بندی

جستجوی فازی هوشمند به دو زبان فارسی و انگلیسی همراه با فیلتر دسته‌بندی، حرف الفبا، اصطلاحات غنی‌شده و صفحه‌بندی.

پارامتر نوع پیش‌فرض توضیحات
q string "" عبارت جستجو به فارسی یا انگلیسی (دارای نرمال‌سازی خودکار حروف فارسی)
category string - اسلاگ دسته‌بندی (مانند crypto) یا نام فارسی آن
letter string - حرف ابتدایی انگلیسی ('A'-'Z' یا '#')
has_deep bool - فیلتر اصطلاحات دارای مقاله کامل و چندبخشی (true/false)
has_formula bool - فیلتر اصطلاحات دارای فرمول ریاضیاتی لاتک (true/false)
page int 1 شماره صفحه (شروع از ۱)
limit int 20 تعداد آیتم در هر صفحه (حداکثر ۱۰۰)
fields string - انتخاب فیلدهای دلخواه با کاما (مانند id,slug,term_en,term_fa)
GET /api/v1/terms/{identifier}
جزئیات کامل اصطلاح

دریافت اطلاعات غنی اصطلاح بر اساس شناسه عددی (مانند 461)، اسلاگ (مانند sharperatio) یا عنوان انگلیسی همراه با فرمول لاتک، نکات کلیدی و بخش‌های تفصیلی.

GET /api/v1/terms/random
اصطلاح تصادفی

دریافت یک یا چند اصطلاح به صورت رندوم با پارامترهای اختیاری `count` (۱ تا ۱۰) و `category` (بسیار کاربردی برای ویجت اصطلاح روز و بات‌های آموزشی).

۳. تکمیل خودکار جستجو (Suggest / Autocomplete)

GET /api/v1/suggest?q={prefix}&limit=10
<5ms Latency

سرویس فوق‌سریع سبک برای جعبه‌های جستجو، Typeahead و پیشنهاد لحظه‌ای به محض تایپ کاربر.

۴. فرمول‌های محاسباتی مالی (LaTeX Formulas)

GET /api/v1/formulas
۴۴ فرمول مالی با لاتک

فهرست کامل فرمول‌های کمی مالی (شامل نسبت شارپ، سورتینو، ترینور، CAPM، بلک-شولز، نقطه سربه‌سر، CAGR و غیره) به همراه معادلات استاندارد لاتک و ترجمه فارسی متغیرها.

۵. کتابخانه‌های اختصاصی و نمونه کدها (SDKs & Examples)

from marketdict_client import MarketDict

client = MarketDict("http://localhost:5000/api/v1")

# 1. جستجوی اصطلاحات مالی
results = client.search(query="نسبت شارپ", limit=3)
for term in results["data"]:
    print(f"{term['term_en']} ({term['term_fa']}) - {term['category_icon']}")

# 2. دریافت جزئیات اصطلاح با فرمول لاتک
sharpe = client.get_term("sharperatio")
print(sharpe["formula"]["formula_en"])

# 3. پیشنهاد لحظه‌ای جستجو
suggestions = client.suggest("bit", limit=5)

# 4. اصطلاح تصادفی روز
daily = client.get_random(has_deep=True)
print("اصطلاح روز:", daily["term_en"])
using MarketDict;

using var client = new MarketDictClient("http://localhost:5000/api/v1");

// ۱. جستجوی اصطلاحات مالی
var search = await client.SearchTermsAsync(query: "نسبت شارپ", limit: 3);
foreach (var term in search.Data)
{
    Console.WriteLine($"{term.TermEn} ({term.TermFa}) - {term.CategoryIcon}");
}

// ۲. دریافت جزئیات و فرمول لاتک
var sharpe = await client.GetTermAsync("sharperatio");
Console.WriteLine(sharpe.Formula?.FormulaEn);

// ۳. تکمیل خودکار جستجو
var suggestions = await client.SuggestAsync("bit", limit: 5);

// ۴. دریافت اصطلاح روز
var daily = await client.GetRandomTermAsync(hasDeep: true);
Console.WriteLine($"اصطلاح روز: {daily.TermEn}");
// جستجوی اصطلاحات مالی با fetch
const response = await fetch('http://localhost:5000/api/v1/terms?q=inflation&limit=5');
const { data, pagination } = await response.json();
console.log(data);

// تکمیل خودکار (<5ms)
const suggestRes = await fetch('http://localhost:5000/api/v1/suggest?q=cap');
const suggestions = await suggestRes.json();
console.log(suggestions.data);
